## GitHub Pages Setup

1. Create a new public GitHub repository.

2. Suggested repository name:

   linda-buluma-portfolio

3. Upload:

   - index.html
   - content-writing.html
   - style.css
   - README.md

4. Open:

   Settings → Pages

5. Under:

   Build and deployment

   select:

   Deploy from a branch

6. Select:

   Branch: main

   Folder: / (root)

7. Click Save.

8. GitHub will generate your public portfolio URL.
